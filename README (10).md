# Evidências sugeridas

Esta pasta documenta capturas que o estudante pode produzir ao executar o DIO Agent no Hermes. Não há imagens simuladas no repositório.

1. Abra o Hermes com o diretório raiz deste projeto como pasta de trabalho.
2. Peça uma análise AppSec do exemplo vulnerável e registre a primeira pergunta de escopo/contexto e a avaliação do agente.
3. Peça que revise a função parametrizada e registre a conclusão e os limites da análise.
4. Se publicar capturas, remova tokens, nomes de usuário, caminhos pessoais, dados de cliente e qualquer segredo.

As evidências devem corresponder a execuções reais e autorizadas. O exemplo é local, efêmero e não usa dados reais.
